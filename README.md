# Arduino-Sentry
Built a real-time face tracking system using Python, OpenCV, and MediaPipe. A webcam detects faces and sends coordinates to an Arduino, which controls two servo motors to automatically follow the target horizontally and vertically.
Python:     3.10.11
MediaPipe:  0.10.9
NumPy:      1.26.1
OpenCV:     4.8.1
pyFirmata:  1.1.0
